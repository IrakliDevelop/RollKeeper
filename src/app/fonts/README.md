# Fonts

Self-hosted latin subsets, loaded with `next/font/local` in `src/app/layout.tsx`.

| File | Family | Source |
|---|---|---|
| `vollkorn-latin-wght-normal.woff2` | Vollkorn (variable 400–900): headings | `@fontsource-variable/vollkorn@5.3.0` |
| `barlow-latin-{400,500,600}-normal.woff2`, `barlow-latin-400-italic.woff2` | Barlow: body and UI | `@fontsource/barlow@5.3.0` |
| `barlow-condensed-latin-{600,700}-normal.woff2` | Barlow Condensed: display numerals | `@fontsource/barlow-condensed@5.3.0` |
